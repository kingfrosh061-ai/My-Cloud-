# My Cloud V1.0 — React + Supabase Foundation

This is the next-stage React version of My Cloud. It preserves the approved landing-page design and adds the first real backend integration points.

Backend:
- Supabase Authentication
- Supabase PostgreSQL
- Supabase private Storage
- Row Level Security
- Per-user 1 TB quota model

Frontend:
- React + Vite
- Responsive mobile-first UI
- Light/dark mode
- Google/email authentication UI
- Upload photos/videos
- Storage usage
- Private files
- Trash/recovery
- Signed downloads

Read `SETUP.md` before deploying.

Important: credentials are intentionally NOT included. You must connect your own Supabase project using `.env.local` / Vercel Environment Variables.
